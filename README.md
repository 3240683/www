# toio de 迷路 & コントローラー コネクター

このプロジェクトは、ゲームコントローラー（Nintendo Switch の Joy-Con / Proコントローラーはもちろん、USB接続の有線コントローラーなど、Web Gamepad API に対応した汎用コントローラー）を使用して、ブラウザ（Google Chrome / Microsoft Edge）経由で **toio™ コア キューブ** を操縦するための JavaScript アプリケーションです。

Web Bluetooth API と Web Gamepad API を利用しているため、複雑なドライバーのインストールやライブラリのビルド環境を用意することなく、簡単に動作させることができます。

🔗 プレイページ: **[https://3240683.github.io/www/](https://3240683.github.io/www/)**
このページにブラウザでアクセスし、PCとtoio™コアキューブ・コントローラーをそれぞれBluetoothでつなぐだけで遊べます。

> 📦 近日公開予定: ローカルでも遊べるダウンロード版を、この後Webサイト上で配布する予定です。

---

## 必要なもの
1. **toio™ コア キューブ**
2. **ゲームコントローラー**
   - Nintendo Switch コントローラー（Joy-Con または Proコントローラー）
   - または、USB接続の有線ゲームパッドなど、Web Gamepad API に対応した汎用コントローラー
3. **Bluetooth を搭載したPC**（toio™ コア キューブとの接続に使用）
4. **Google Chrome** または **Microsoft Edge** ブラウザ（Web Bluetooth API が有効なブラウザ）
5. （ダウンロード版をローカルで動かす場合のみ）**Node.js**

## 使い方

### 🌐 オンラインでプレイする（推奨）
1. **Google Chrome** または **Microsoft Edge** で **[https://3240683.github.io/www/](https://3240683.github.io/www/)** にアクセスします。
2. 下記の「コントローラーの準備」「toioへの接続」の手順に進みます。
3. あとはコントローラーで toio を操作するだけです。インストール作業は不要です。

### 💾 ダウンロード版で遊ぶ（近日公開・インターネットに繋がない環境向け）
Web BluetoothとWeb Gamepad APIの処理はすべてブラウザ内で完結するため、**インターネットに接続できる環境であれば、ローカルで遊ぶ場合もオンライン版（上記のプレイページ）にそのままアクセスするだけで問題ありません。** PCの前にあるtoioやコントローラーとは、Webサイト経由であっても直接Bluetoothで通信します。

ダウンロード版は、インターネットに接続できない環境（会場のWi-Fiが使えない、オフラインで展示したい等）でも遊べるようにするための配布物で、この後Webサイト上に公開する予定です。公開後は、ダウンロードしたファイル一式をブラウザで直接開くのではなく、同梱の簡易サーバー（`node server.js`）を経由してアクセスする形になります（Web Bluetooth API はセキュリティ保護された接続 `https` または `localhost` でのみ動作するため）。

## コントローラーの準備

### 🎮 Nintendo Switch コントローラー（Bluetooth接続）の場合
1. Windows の「設定」 > 「Bluetooth とその他のデバイス」を開き、Bluetooth をオンにします。
2. コントローラーをペアリングモードにします。
   - **Joy-Con:** スライドレールの間にある「シンクロボタン」を長押しして、ランプが往復点滅するのを待ちます。
   - **Proコントローラー:** USB端子横の「シンクロボタン」を長押しします。
3. Windows の「デバイスの追加」からコントローラー（`Joy-Con (L)`、`Joy-Con (R)`、または `Pro Controller`）を選択し、ペアリングを完了させます。

### 🔌 有線（USB）コントローラーの場合
1. コントローラーをPCのUSBポートに接続します。ペアリング作業は不要です。
2. Windowsが自動的にデバイスを認識します。認識されない場合は、コントローラー付属のドライバーをインストールしてください。

### 共通: ブラウザでの認識確認
1. ページを開いた状態で、接続したコントローラーのいずれかのボタン（A, B, X, Yなど）を押します。
2. 画面右側の「コントローラー」エリアが**「検出済み」**になり、スティックやボタンの動きがリアルタイムに反映されることを確認します。
   - ブラウザの仕様上、ボタンを1回以上押さないと Web Gamepad API が接続を検知しません。

## toio™ コア キューブへの接続
1. toio の電源を入れます。
2. 画面左側の **「toio に接続する」** ボタンをクリックします。
3. ブラウザのポップアップ画面が表示されるので、一覧から **「toio Core Cube」** を選択して「ペアリング」をクリックします。
4. 接続に成功すると、toio から接続音が鳴り、LEDが緑（デフォルト）に点灯します。

## 操作方法

### 🎮 コントローラーでの操作
Nintendo Switch コントローラー・有線コントローラーのどちらでも、同じボタン配置で操作できます。
- **左スティック (または右スティック):**
  - **前進 / 後退 / 旋回:** スティックを倒した方向に toio が走ります。
- **アクションボタン:**
  - **A ボタン（または対応するボタン）:** LEDが緑に光り、接続音が鳴ります。
  - **B ボタン:** LEDが赤に光り、ダメージ音が鳴ります。
  - **X ボタン:** LEDが青に光り、レベルアップ音が鳴ります。
  - **Y ボタン:** LEDが黄に光り、コイン音が鳴ります。

  ※ コントローラーの機種によってボタンの物理配置やラベルが異なる場合があります。Web Gamepad API 上のボタン番号（0〜3番）に対応しているため、Xboxパッドなど別配列のコントローラーでは対応するボタン位置が変わることがあります。

### ⌨️ キーボードでの操作 (コントローラーがない場合)
コントローラーが手元にない場合や認識しない場合でも、キーボードで操作できます。
- **W キー:** 前進
- **S キー:** 後退
- **A キー:** 左旋回
- **D キー:** 右旋回
- **1, 2, 3, 4 キー:** それぞれ LEDカラーチェンジ ＋ 効果音が鳴ります。

## トラブルシューティング

- **「toio に接続する」ボタンを押してもデバイスが見つからない**
  - PCの Bluetooth 機能がオンになっているか確認してください。
  - toio の電源が入っているか（ランプが点滅しているか）確認してください。
  - すでに他のアプリ（スマホアプリなど）に toio が接続されている場合は、一度接続を切ってください。

- **コントローラーが認識されない**
  - ブラウザの仕様上、コントローラーのボタンを1回以上押さないと Gamepad API が接続を検知しません。コントローラーのボタンをいくつか押してみてください。
  - 有線コントローラーの場合、USBポートやケーブルを変えて接続し直してみてください。
  - Windows 側でコントローラーが正しく接続されているか（コントロールパネルの「ゲームコントローラーの設定」で入力が反映されるか）確認してください。

- **Web Bluetooth がサポートされていないとエラーが出る**
  - Safari、Firefox、Internet Explorer では Web Bluetooth は動作しません。必ず **Chrome** または **Edge** をご使用ください。
  - アドレスバーのURLが [https://3240683.github.io/www/](https://3240683.github.io/www/)（オンライン版）または `http://localhost:3000`（ダウンロード版をローカル起動している場合）になっているか確認してください。IPアドレス（例: `http://192.168.x.x`）やファイルパス（`file:///...`）で開くと、Web Bluetooth API はセキュリティ制限により無効化されます。
